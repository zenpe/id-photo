# 电子照手动调试归档

此目录的两个 JavaScript 文件是旧版微信开发者工具控制台脚本，不是 Node 测试，不参与 CI。
旧脚本中的存储格式、页面结构和日志可能与当前版本不同，不作为发布验收依据。

当前检查流程：使用公开测试照片制作 → 开启“保存到电子照” → 免费保存 → 在电子照页预览和再次保存。
本地最多两张，满额应提示先删除，不覆盖旧照片；清理本地照片不影响手机相册。
相册拒绝权限后重试不能重复生成，启用广告时不重复观看同一任务的已完成广告。

自动回归见 `tests/loading-flow.test.cjs`、`tests/ad-manager.test.cjs`；开发工具中验证真实权限及存储大小。
